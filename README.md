# Git Activity 3: Repository Creation and Basic Git Commands

**Course:** CS223 – Application Development and Emerging Technologies

## Objective
Practice repository creation, cloning, staging, committing, pushing, pulling, branching, switching branches, and merging using Git and GitHub.

## Activity files
- `git-activity.txt` — sample text file used for Git commands.
- `GIT-COMMANDS.md` — commands and steps to reproduce the activity locally.

## Note
GitHub web changes made for demonstration do not replace running the required commands in a local terminal. Follow `GIT-COMMANDS.md` and capture your own screenshots if your instructor requires evidence.
